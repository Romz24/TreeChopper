**Tree Chopper** is a simple mod that chops down a whole tree at once. Break the bottom log with an axe and the entire trunk falls, instead of clearing it block by block.

*   Recognizes axes and wood from other mods, not just vanilla (e.g. Biomes O' Plenty, Forestry, Tinkers' Construct, Gravity Suite, Aether Legacy, Lost Aether, Galacticraft, Immersive Engineering, Animalium), plus IC2 Experimental's electric chainsaw.
*   Hold SHIFT to skip the effect on a single tree (or reverse that behavior in the config).
*   Saplings are replanted automatically after a tree falls.
*   Durability lost per tree is configurable, including disabling durability loss entirely. IC2 Experimental's electric chainsaw drains real charge (EU) instead, also configurable.
*   Works server-side only, but installing it on the client too is recommended, since server-only leaves the block-breaking animation out of sync for other players.

#### Usage
Type the in-game command "/tch help" for more info.

#### Add new wood or axe
Add the item's UnlocalizedName to `treechopper.cfg` (config/treechopper/ in your Minecraft folder), inside the appropriate list. Use the in-game command "/tch printName 1" to print item names as you interact with them.
